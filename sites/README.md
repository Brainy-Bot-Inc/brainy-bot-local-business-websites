# Local Business Websites

Starter websites for local businesses that don't have one yet. Each business has its
own folder, and all sites share the same design so they're cheap to build and easy to
update.

## Files

- `index.html` — the page. Open this in any text editor (Notepad, VS Code, Sublime) and it's
  straightforward to edit: change the business name, address, phone, hours, services, and
  story inside the `<body>` section.
- `styles.css` — the shared design. No HTML knowledge needed to change colors, fonts, or
  spacing here if you read the comments.
- `README.md` — this file.

## How to edit (no coding required)

1. Open the business's `index.html` in a text editor.
2. Find the `[Business Name]`, `[Address]`, `[Phone]`, `[Email]`, `[Tagline]`, and
   `[Service 1]` / `[Service 2]` placeholders.
3. Replace them with your real details.
4. Save the file.

## How to publish (free)

1. Create a free account at GitHub.com.
2. Make a new repository (repo).
3. Upload this whole folder to the repo.
4. In repo Settings → Pages → Source: "Deploy from a branch" → pick `main` → save.
5. Your live site is `https://<your-username>.github.io/<repo-name>/`.

## Making it your business

The sites are intentionally minimal so they load fast and are easy to build on. To add
pages, photos, a contact form, or online booking, reply to the owner's email and we'll
customize from here.

*Note: These are starter templates. Each business email drafts below go with the matching
